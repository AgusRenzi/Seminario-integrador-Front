# EstadoTag

Etiqueta de estado (variante de `.ac-tag`) para lotes, semillas, insumos y campañas. Siempre lleva la palabra; el color solo acompaña.

- **Provee el consumidor:** el estado tal como lo devuelve el back.
- Lote: `Libre` lime · `En uso` steel-soft · `Sembrado` lime-strong · `Cosechado` forest con texto crema.
- Semilla/Insumo: `Activa` lime · `Inactiva` line-cream con texto ink-muted.
- Campaña: `Abierta` lime-strong · `Cerrada` line-cream.
- Un estado desconocido se muestra con el `.ac-tag` neutro.
